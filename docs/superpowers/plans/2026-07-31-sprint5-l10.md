# Sprint 5 — L10 Meetings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reunión L10 en vivo (Segue, Scorecard, Rock Review, Headlines, To-Do List, IDS,
Conclude) con timer opcional por sección, notas persistidas, referencias a Rocks/Issues
discutidos, y cierre con rating 1-10. Incluye `Todo` como módulo propio (repositorio + rutas),
ya que este sprint es el primero que lo necesita.

**Architecture:** Mismo patrón que Sprint 2-4: repositorios tenant-aware → rutas Fastify con
`requireTenant(app)` → clientes API tipados → páginas React dentro de `AppLayout`. La vista de
reunión en vivo reutiliza `rocksApi`, `issuesApi`, `scorecardApi` y `tenantApi` ya existentes
(Sprint 2-4) en vez de reconstruir esas vistas — cada sección de la agenda es principalmente
composición, no lógica nueva.

**Tech Stack:** Fastify + Zod + Prisma (backend, ya existente); React + Vite + Ant Design (sin
dependencias nuevas — el timer usa `setInterval` + estado local, no hace falta ninguna librería).

## Global Constraints

- **Multitenancy (CLAUDE.md §4):** ningún controller/route llama `prisma.<modelo>.*`
  directamente. `L10MeetingRepository`, `L10AgendaItemLogRepository`, `TodoRepository`,
  `constructor(private tenantId: string)`, todo `where` inyecta `tenantId`.
- **Patrón de repositorio establecido:** `update`/`delete` usan `updateMany`/`deleteMany` con
  `{ id, tenantId }` en el `where`; `count === 0` → `null`/`false`.
- **`requireTenant(app)`** en cada ruta — nunca `app.addHook` manual.
- **Rules of Hooks:** todo hook antes de los guards `!token`/`mustChangePassword`, que van justo
  antes del `return (`.
- **`L10AgendaItemLog.meeting`** usa una FK compuesta `[meetingId, tenantId]` hacia
  `L10Meeting[id, tenantId]` (ya en el schema) — aun así, la ruta que crea un log siempre
  comprueba `meetingRepo.findById(meetingId)` primero y devuelve 404 si no existe, en vez de
  dejar que una violación de FK burbujee como 500 genérico (mismo patrón que
  `routes/rocks.ts` al crear un milestone).
- **Decisión ya tomada (roadmap, pendiente de detallar):** `Todo` estrena repositorio y rutas
  propias en este sprint (`TodoRepository`, `routes/todos.ts`) — los necesita la sección To-Do
  List de la reunión y ningún sprint anterior los creó. **No** se construye una página `/todos`
  independiente — Todos se gestionan únicamente dentro de la vista de reunión en vivo
  (`originatingMeetingId` es el único vínculo que pide el schema; una lista global de Todos no
  está en el alcance de este sprint, YAGNI — se puede añadir en un sprint futuro si se pide).
- **Secciones de la agenda y su almacenamiento**, mapeado directo del schema existente (no se
  añaden campos nuevos a `L10Meeting`): Segue → `segueNotes`; Scorecard → solo lectura (resumen
  compacto vía `scorecardApi`, sin campo propio); Rock Review → lista de Rocks **sin filtrar por
  trimestre** vía `rocksApi.list()` (mismo default que `RocksBoard.tsx`, que tampoco filtra por
  trimestre salvo que el usuario lo pida — no reinventar ese criterio aquí), con notas de
  discusión guardadas como `L10AgendaItemLog` (`itemType: 'rock_review'`); Headlines →
  `headlines`; To-Do List → `Todo` filtrados por `status: 'open'`, creación inline con
  `originatingMeetingId`; IDS → lista de Issues **sin filtrar por estado** vía
  `issuesApi.list()` (deja ver también las ya resueltas/descartadas durante la reunión, no solo
  las activas), con notas como `L10AgendaItemLog` (`itemType: 'issue'`) y un `Select` de estado
  inline por fila que reutiliza `issuesApi.update` — así la sección IDS puede resolver o
  descartar un issue sin salir de la reunión; Conclude → `concludeNotes` + `overallRating`,
  enviados juntos vía `POST /l10/:id/close`.
- **Timer por sección:** puramente de cliente (`setInterval` + estado local en cada
  `AgendaSection`), no se persiste en el backend — si se recarga la página el timer de la
  sección activa vuelve a 0. No se pidió persistencia de tiempo, YAGNI.
- **Diseño (`docs/DESIGN_BRIEF.md` §"L10 Meeting"):** el panel de sección activo usa
  `--glass-bg-elevated` (más nítido), las secciones colapsadas usan `--glass-bg-secondary` (más
  translúcidas) — clases nuevas `.agenda-section--active`/`.agenda-section--collapsed` en
  `front/src/theme/glass.css`, no reutilizar `.glass-panel` tal cual (esa opacidad es para
  Rocks/Issues, no para este layout de acordeón).
- **Cada módulo lleva tests + cobertura + `.md` de funcionalidad** — regla del usuario, no
  negociable. `server/src/repositories/**` y `server/src/routes/**` ya están en
  `coverage.include` de `server/vitest.config.ts`, no hace falta tocarlo.
- **Sin ACL por rol** — cualquier miembro del tenant puede crear/editar/borrar/cerrar cualquier
  reunión, todo o log de agenda, igual que el resto de módulos.
- **Nadie hace `git commit`** salvo el usuario.

```typescript
// server/src/repositories/TodoRepository.ts
import type { Todo, TodoStatus } from '@prisma/client';
import { prisma } from '../lib/prisma.js';

export interface TodoFilters {
  status?: TodoStatus;
  ownerUserId?: string;
}

export interface CreateTodoInput {
  title: string;
  ownerUserId: string;
  dueDate?: Date;
  originatingMeetingId?: string;
}

export type UpdateTodoInput = Partial<{
  title: string;
  ownerUserId: string;
  dueDate: Date | null;
  status: TodoStatus;
}>;

export class TodoRepository {
  constructor(private tenantId: string) {}

  findAll(filters: TodoFilters = {}): Promise<Todo[]> {
    return prisma.todo.findMany({
      where: {
        tenantId: this.tenantId,
        ...(filters.status ? { status: filters.status } : {}),
        ...(filters.ownerUserId ? { ownerUserId: filters.ownerUserId } : {}),
      },
      orderBy: { dueDate: 'asc' },
    });
  }

  findById(id: string): Promise<Todo | null> {
    return prisma.todo.findFirst({ where: { id, tenantId: this.tenantId } });
  }

  create(data: CreateTodoInput): Promise<Todo> {
    return prisma.todo.create({ data: { ...data, tenantId: this.tenantId } });
  }

  async update(id: string, data: UpdateTodoInput): Promise<Todo | null> {
    const result = await prisma.todo.updateMany({ where: { id, tenantId: this.tenantId }, data });
    if (result.count === 0) return null;
    return this.findById(id);
  }

  async delete(id: string): Promise<boolean> {
    const result = await prisma.todo.deleteMany({ where: { id, tenantId: this.tenantId } });
    return result.count > 0;
  }
}
```

```typescript
import type { FastifyInstance } from 'fastify';
import { z } from 'zod';
import { requireTenant } from '../middleware/resolveTenantContext.js';
import { TodoRepository } from '../repositories/TodoRepository.js';

const statusEnum = z.enum(['open', 'done']);

  ownerUserId: z.string().min(1),
  dueDate: z.coerce.date().optional(),

});

  title: z.string().min(1).optional(),
  ownerUserId: z.string().min(1).optional(),
  dueDate: z.coerce.date().nullable().optional(),
  status: statusEnum.optional(),
});

  status: statusEnum.optional(),
  ownerUserId: z.string().optional(),
});

export default async function todoRoutes(app: FastifyInstance): Promise<void> {

    const repo = new TodoRepository(request.tenantId as string);
    return repo.findAll(query);
  });

  app.post('/', { preHandler: requireTenant(app) }, async (request, reply) => {
    const body = createTodoSchema.parse(request.body);
    const repo = new TodoRepository(request.tenantId as string);
    const todo = await repo.create(body);
    return reply.code(201).send(todo);
  });

  app.patch('/:id', { preHandler: requireTenant(app) }, async (request, reply) => {
    const { id } = request.params as { id: string };
    const body = updateTodoSchema.parse(request.body);
    const repo = new TodoRepository(request.tenantId as string);
    const todo = await repo.update(id, body);
    if (!todo) return reply.code(404).send({ error: 'Todo not found' });
    return todo;

    const { id } = request.params as { id: string };
    const repo = new TodoRepository(request.tenantId as string);
    const deleted = await repo.delete(id);
```

```tsx
// front/src/components/TodoFormModal.tsx
import { Button, DatePicker, Form, Input, message, Modal, Popconfirm, Select } from 'antd';
import dayjs from 'dayjs';
import { useEffect, useState } from 'react';
import { todosApi, type Todo, type TodoStatus } from '../lib/todosApi';
import type { TenantMember } from '../lib/tenantApi';

export interface TodoFormModalProps {
  open: boolean;
  todo?: Todo;
  members: TenantMember[];
  meetingId?: string;
  onClose: () => void;
  onSaved: () => void;
}

interface FormValues {
  title: string;
  ownerUserId: string;
  dueDate?: dayjs.Dayjs;
  status?: TodoStatus;
}

function errorMessage(e: unknown): string {
  return e instanceof Error ? e.message : 'Something went wrong';
}

export function TodoFormModal({ open, todo, members, meetingId, onClose, onSaved }: TodoFormModalProps) {
  const [form] = Form.useForm<FormValues>();
  const [saving, setSaving] = useState(false);

  useEffect(() => {
    form.setFieldsValue(
      todo
        ? { title: todo.title, ownerUserId: todo.ownerUserId, dueDate: todo.dueDate ? dayjs(todo.dueDate) : undefined, status: todo.status }
        : {}
    );
  }, [todo, form]);

  async function handleSubmit(values: FormValues) {
    setSaving(true);
    try {
      const dueDate = values.dueDate ? values.dueDate.toISOString() : undefined;
      if (todo) {
        await todosApi.update(todo.id, { title: values.title, ownerUserId: values.ownerUserId, dueDate: dueDate ?? null, status: values.status });
      } else {
        await todosApi.create({
          title: values.title,
          ownerUserId: values.ownerUserId,
          dueDate,
          ...(meetingId ? { originatingMeetingId: meetingId } : {}),
        });
      }
      onSaved();
    } catch (e) {
      message.error(errorMessage(e));
    } finally {
      setSaving(false);
    }
  }

  async function handleDelete() {
    if (!todo) return;
    try {
      await todosApi.remove(todo.id);
      onSaved();
      onClose();
    } catch (e) {
      message.error(errorMessage(e));
    }
  }

  return (
    <Modal open={open} onCancel={onClose} footer={null} title={todo ? 'Editar to-do' : 'Nuevo to-do'} destroyOnHidden>
      <Form form={form} layout="vertical" onFinish={handleSubmit}>
        <Form.Item name="title" label="Título" rules={[{ required: true, message: 'Introduce un título' }]}>
          <Input />
        </Form.Item>
        <Form.Item name="ownerUserId" label="Owner" rules={[{ required: true, message: 'Elige un owner' }]}>
          <Select aria-label="Owner" options={members.map((m) => ({ value: m.userId, label: m.fullName }))} />
        </Form.Item>
        <Form.Item name="dueDate" label="Fecha límite">
          <DatePicker style={{ width: '100%' }} />
        </Form.Item>
        {todo && (
          <Form.Item name="status" label="Estado">
            <Select
              aria-label="Estado"
              options={[
                { value: 'open', label: 'Open' },
                { value: 'done', label: 'Done' },
              ]}
            />
          </Form.Item>
        )}
        <Button type="primary" htmlType="submit" loading={saving} block>
          Guardar
        </Button>
      </Form>

      {todo && (
        <div style={{ marginTop: 24 }}>
          <Popconfirm
            title="¿Borrar este to-do? Esta acción no se puede deshacer."
            onConfirm={handleDelete}
            okText="Borrar"
            cancelText="Cancelar"
          >
            <Button danger block>
              Borrar to-do
            </Button>
          </Popconfirm>
        </div>
      )}
    </Modal>
  );
}
```

```tsx
// front/src/components/AgendaSection.tsx
import { Button, Space, Typography } from 'antd';
import { useEffect, useState, type ReactNode } from 'react';

export interface AgendaSectionProps {
  title: string;
  targetMinutes: number;
  active: boolean;
  onActivate: () => void;
  children: ReactNode;
}

function formatTime(totalSeconds: number): string {
  const minutes = Math.floor(totalSeconds / 60);
  const seconds = totalSeconds % 60;
  return `${String(minutes).padStart(2, '0')}:${String(seconds).padStart(2, '0')}`;
}

export function AgendaSection({ title, targetMinutes, active, onActivate, children }: AgendaSectionProps) {
  const [seconds, setSeconds] = useState(0);
  const [paused, setPaused] = useState(false);

  useEffect(() => {
    if (!active || paused) return;
    const interval = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => clearInterval(interval);
  }, [active, paused]);

  const overTarget = seconds >= targetMinutes * 60;

  return (
    <div className={`agenda-section ${active ? 'agenda-section--active' : 'agenda-section--collapsed'}`}>
      <div
        style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center' }}
        onClick={active ? undefined : onActivate}
      >
        <Typography.Text strong>{title}</Typography.Text>
        {active && (
          <Space>
            <Typography.Text type={overTarget ? 'danger' : 'secondary'}>
              {formatTime(seconds)} / {targetMinutes}:00
            </Typography.Text>
            <Button size="small" onClick={() => setPaused((p) => !p)}>
              {paused ? 'Reanudar' : 'Pausar'}
            </Button>
          </Space>
        )}
      </div>
      {active && <div style={{ marginTop: 12 }}>{children}</div>}
    </div>
  );
}
```

```tsx
      .catch((e) => message.error(errorMessage(e)));
  }

  useEffect(() => {
    if (!id) return;
    l10Api
      .get(id)
      .then(setMeeting)
      .catch((e) => message.error(errorMessage(e)));
    l10Api
      .listAgendaItems(id)
      .then(setAgendaItems)
      .catch((e) => message.error(errorMessage(e)));
  }, [id, activeTenantId]);

  useEffect(() => {
    rocksApi.list().then(setRocks).catch((e) => message.error(errorMessage(e)));
    issuesApi.list().then(setIssues).catch((e) => message.error(errorMessage(e)));
    scorecardApi.listMetrics({ isActive: true }).then(setMetrics).catch((e) => message.error(errorMessage(e)));
    scorecardApi.listEntries(1).then(setEntries).catch((e) => message.error(errorMessage(e)));
    refetchTodos();
    tenantApi.listMembers().then(setMembers).catch((e) => message.error(errorMessage(e)));
  }, [activeTenantId]);

  async function saveSegueNotes(value: string) {
    if (!id) return;
    try {
      const updated = await l10Api.update(id, { segueNotes: value });
      setMeeting(updated);
    } catch (e) {
      message.error(errorMessage(e));
    }
  }

  async function saveHeadlines(value: string) {
    if (!id) return;
    try {
      const updated = await l10Api.update(id, { headlines: value });
      setMeeting(updated);
    } catch (e) {
      message.error(errorMessage(e));
    }
  }

  async function logRockNote(rockId: string) {
    if (!id) return;
    const notes = rockNoteDrafts[rockId];
    if (!notes) return;
    try {
      const log = await l10Api.logAgendaItem(id, { itemType: 'rock_review', referenceId: rockId, notes });
      setAgendaItems((prev) => [...prev, log]);
      setRockNoteDrafts((prev) => ({ ...prev, [rockId]: '' }));
    } catch (e) {
      message.error(errorMessage(e));
    }
  }

  async function logIssueNote(issueId: string) {
    if (!id) return;
    const notes = issueNoteDrafts[issueId];
    if (!notes) return;
    try {
      const log = await l10Api.logAgendaItem(id, { itemType: 'issue', referenceId: issueId, notes });
      setAgendaItems((prev) => [...prev, log]);
      setIssueNoteDrafts((prev) => ({ ...prev, [issueId]: '' }));
    } catch (e) {
      message.error(errorMessage(e));
    }
  }

  async function changeIssueStatus(issueId: string, status: IssueStatus) {
    try {
      const updated = await issuesApi.update(issueId, { status });
      setIssues((prev) => prev.map((i) => (i.id === issueId ? updated : i)));
    } catch (e) {
      message.error(errorMessage(e));
    }
  }

  async function closeMeeting() {
    if (!id || ratingDraft === null) return;
    try {
      const updated = await l10Api.close(id, { overallRating: ratingDraft, concludeNotes: concludeNotesDraft || undefined });
      setMeeting(updated);
      message.success('Reunión cerrada');
    } catch (e) {
      message.error(errorMessage(e));
    }
  }

  if (!token) return <Navigate to="/login" replace />;
  if (user?.mustChangePassword) return <Navigate to="/change-password" replace />;

  if (!meeting) {
    return (
      <AppLayout title="Reunión L10">
        <div>Cargando…</div>
      </AppLayout>
    );
  }

  const latestEntryFor = (metricId: string) => entries.find((e) => e.metricId === metricId);

  return (
    <AppLayout title="Reunión L10">
      <AgendaSection title="Segue" targetMinutes={5} active={activeSection === 'segue'} onActivate={() => setActiveSection('segue')}>
        <Input.TextArea
          rows={3}
          placeholder="Notas de segue"
          defaultValue={meeting.segueNotes ?? ''}
          onBlur={(e) => saveSegueNotes(e.target.value)}
        />
      </AgendaSection>

      <AgendaSection
        title="Scorecard"
        targetMinutes={5}
        active={activeSection === 'scorecard'}
        onActivate={() => setActiveSection('scorecard')}
      >
        <List
          dataSource={metrics}
          renderItem={(metric) => {
            const entry = latestEntryFor(metric.id);
            const status = evaluateGoal(entry?.actualValue ?? null, metric.goalValue, metric.comparison);
            return (
              <List.Item>
                {metric.name}: {entry ? entry.actualValue : '—'} {metric.unit} (objetivo {metric.goalValue}) —{' '}
                <Tag color={status === 'met' ? 'green' : status === 'missed' ? 'red' : 'default'}>{status}</Tag>
              </List.Item>
            );
          }}
        />
      </AgendaSection>

      <AgendaSection title="Rock Review" targetMinutes={5} active={activeSection === 'rocks'} onActivate={() => setActiveSection('rocks')}>
        <List
          dataSource={rocks}
          renderItem={(rock: Rock) => (
            <List.Item>
              <div style={{ width: '100%' }}>
                <div>
                  {rock.title} — <Tag>{rock.status}</Tag>
                </div>
                <div style={{ display: 'flex', gap: 8, marginTop: 4 }}>
                  <Input
                    size="small"
                    placeholder="Nota de discusión"
                    value={rockNoteDrafts[rock.id] ?? ''}
                    onChange={(e) => setRockNoteDrafts((prev) => ({ ...prev, [rock.id]: e.target.value }))}
                  />
                  <Button size="small" onClick={() => logRockNote(rock.id)}>
                    Añadir nota
                  </Button>
                </div>
              </div>
            </List.Item>
          )}
        />
      </AgendaSection>

      <AgendaSection
        title="Headlines"
        targetMinutes={5}
        active={activeSection === 'headlines'}
        onActivate={() => setActiveSection('headlines')}
      >
        <Input.TextArea
          rows={3}
          placeholder="Titulares de clientes y empleados"
          defaultValue={meeting.headlines ?? ''}
          onBlur={(e) => saveHeadlines(e.target.value)}
        />
      </AgendaSection>

      <AgendaSection title="To-Do List" targetMinutes={5} active={activeSection === 'todos'} onActivate={() => setActiveSection('todos')}>
        <Button style={{ marginBottom: 8 }} onClick={() => setCreatingTodo(true)}>
          Nuevo to-do
        </Button>
        <List
          dataSource={todos}
          renderItem={(todo: Todo) => (
            <List.Item>
              {todo.title} — {members.find((m) => m.userId === todo.ownerUserId)?.fullName ?? '—'}
            </List.Item>
          )}
        />
      </AgendaSection>

      <AgendaSection title="IDS" targetMinutes={60} active={activeSection === 'ids'} onActivate={() => setActiveSection('ids')}>
        <List
          dataSource={issues}
          renderItem={(issue: Issue) => (
            <List.Item>
              <div style={{ width: '100%' }}>
                <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center' }}>
                  <span>{issue.title}</span>
                  <Select
                    size="small"
                    style={{ width: 140 }}
                    value={issue.status}
                    options={ISSUE_STATUS_OPTIONS}
                    onChange={(status) => changeIssueStatus(issue.id, status)}
                  />
                </div>
                <div style={{ display: 'flex', gap: 8, marginTop: 4 }}>
                  <Input
                    size="small"
                    placeholder="Nota de discusión"
                    value={issueNoteDrafts[issue.id] ?? ''}
                    onChange={(e) => setIssueNoteDrafts((prev) => ({ ...prev, [issue.id]: e.target.value }))}
                  />
                  <Button size="small" onClick={() => logIssueNote(issue.id)}>
                    Añadir nota
                  </Button>
                </div>
              </div>
            </List.Item>
          )}
        />
      </AgendaSection>

      <AgendaSection
        title="Conclude"
        targetMinutes={5}
        active={activeSection === 'conclude'}
        onActivate={() => setActiveSection('conclude')}
      >
        <div style={{ display: 'flex', flexDirection: 'column', gap: 12 }}>
          <label>
            Rating (1-10)
            <InputNumber
              aria-label="Rating"
              min={1}
              max={10}
              style={{ width: '100%' }}
              value={ratingDraft}
              onChange={setRatingDraft}
            />
          </label>
          <Input.TextArea
            rows={3}
            placeholder="Notas de cierre"
            value={concludeNotesDraft}
            onChange={(e) => setConcludeNotesDraft(e.target.value)}
          />
          <Button type="primary" disabled={ratingDraft === null} onClick={closeMeeting}>
            Cerrar reunión
          </Button>
        </div>
      </AgendaSection>

      {creatingTodo && (
        <TodoFormModal
          open
          members={members}
          meetingId={id}
          onClose={() => setCreatingTodo(false)}
          onSaved={() => {
            setCreatingTodo(false);
            refetchTodos();
          }}
        />
      )}
    </AppLayout>
  );
}
```

```markdown
# L10 Meetings

## Qué hace

Reunión semanal Level 10 de EOS: agenda fija de 7 secciones (Segue, Scorecard, Rock Review,
Headlines, To-Do List, IDS, Conclude) con timer opcional por sección en el frontend (no
persistido). Todas las rutas requieren `Authorization: Bearer <token>` y `X-Tenant-Id`.

- `GET /l10?status=scheduled|in_progress|completed` — lista las reuniones del tenant activo,
  más recientes primero. Omitir `status` devuelve todas.
- `POST /l10` — crea una reunión. Body: `{ meetingDate, facilitatorUserId }`. Siempre arranca en
  `status: 'scheduled'`.
- `GET /l10/:id` — 404 si no existe en el tenant activo.
- `PATCH /l10/:id` — actualiza cualquier subconjunto de `meetingDate`, `facilitatorUserId`,
  `status`, `segueNotes`, `headlines`. Así es como el frontend guarda las notas de Segue y
  Headlines (una petición por sección al perder el foco del textarea).
- `DELETE /l10/:id` — 204 en éxito, 404 si no existía.
- `POST /l10/:id/close` — body `{ overallRating (1-10), concludeNotes? }`. Fija `status:
  'completed'` y los dos campos de conclusión en una sola llamada — es el único sitio donde se
  puede cerrar una reunión.
- `GET /l10/:id/agenda-items` — lista los `L10AgendaItemLog` registrados durante esta reunión
  (notas de discusión sobre Rocks/Issues). 404 si la reunión no existe.
- `POST /l10/:id/agenda-items` — registra una nota de discusión. Body: `{ itemType:
  'rock_review'|'issue'|'todo', referenceId, notes? }`. 404 si la reunión no existe — se
  comprueba explícitamente antes de intentar el insert, en vez de dejar que una violación de la
  FK compuesta `[meetingId, tenantId]` del schema burbujee como 500.

## Qué NO guarda el schema (y por qué el frontend lo resuelve componiendo otros módulos)

`L10Meeting` no tiene un campo de notas por cada sección — solo `segueNotes`, `headlines`,
`concludeNotes`. Las secciones Scorecard, Rock Review, To-Do List e IDS no tienen "notas de
reunión" propias: Scorecard se muestra en modo solo-lectura reutilizando `scorecardApi`; Rock
Review e IDS reutilizan `rocksApi`/`issuesApi` y registran cualquier nota de discusión como
`L10AgendaItemLog`; To-Do List reutiliza `Todo` filtrado por `status: 'open'`, con la opción de
crear uno nuevo enlazado a la reunión vía `originatingMeetingId`.

## Permisos

Sin ACL por rol, igual que el resto de módulos.

## Frontend

`front/src/lib/l10Api.ts` envuelve estos endpoints. `front/src/pages/L10MeetingsPage.tsx` es la
lista + creación de reuniones. `front/src/pages/L10LiveMeetingPage.tsx` es la vista en vivo,
compuesta de 7 `front/src/components/AgendaSection.tsx` (acordeón con timer local, panel activo
en `--glass-bg-elevated`, colapsados en `--glass-bg-secondary` — ver `docs/DESIGN_BRIEF.md`).
```

```markdown
# Todos

## Qué hace

To-Dos de EOS: tareas de acción corta con un owner y una fecha límite opcional, que pueden
```
